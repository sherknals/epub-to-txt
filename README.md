## ✨ What This App Does

An EPUB file is not really a text file. It is a small bundle of pages, stylesheets, images, and metadata zipped together into a single container. That design is perfect for ereaders and awkward for everything else. If you have ever tried to copy text out of an EPUB by hand, you already know the pain: broken lines, stray formatting characters, footnote markers landing in the middle of a sentence, and chapters that tumble into one another with no separation at all.

EPUB to TXT solves exactly that problem. It reads the container, pulls out the actual reading text, cleans up the mess, and writes one tidy `.txt` file. Chapter headings stay where they belong, paragraphs stay together, and the file is saved in UTF-8 so accents, curly quotes, and non-English characters survive intact instead of turning into question marks.

The result is a file you can open in Notepad, load onto an old e-reader, feed into a text-to-speech tool, drop into a note app, or search with a simple Ctrl+F. Plain text works everywhere, and it always will.

## 💡 Key Features

**Clean UTF-8 output.** Every file is written in UTF-8, the modern standard for text encoding. Accented letters, curly quotation marks, em dashes, and characters from non-Latin scripts all come through correctly instead of degrading into garbled symbols.

**Real chapter breaks.** Chapters are separated by clear, consistent breaks so you can see where one ends and the next begins. This makes long books far easier to navigate in a plain text editor and much easier to split into sections later if you need to.

**Readable paragraph structure.** The converter preserves paragraph boundaries rather than flattening everything into one enormous wall of text. You get line breaks where the author intended them, not wherever the original page layout happened to wrap.

**Stripped of clutter.** Formatting codes, style declarations, and layout instructions are removed. What remains is the text a reader would actually read.

**Local and private.** The conversion happens on your own computer. Your book is not uploaded anywhere, and you do not need an internet connection to convert a file once the application is on your machine.

**Works with a single click.** There is no batch scripting, no syntax to learn, and no configuration file to edit. Choose a file, choose a destination, and go.

## 🧭 Tips for Best Results

Keep your EPUB files in a folder you can find easily, such as a dedicated Books folder, so browsing for them is quick. Name your output files clearly — a title plus the author's surname is a reliable habit. If you convert several books from the same series, save them into one folder so they sit together. When a book includes footnotes or endnotes, skim the output once afterwards to confirm they landed where you expect; note placement varies between publishers, and a quick check saves confusion later. Finally, keep your original EPUB files. The text version is for reading and searching, but the original preserves images and cover art that plain text cannot carry.
